# NLP-Course
Exercises and projects for the Natural Language Processing (NLP) course at the Hebrew University of Jerusalem.

## Exercise 1: Language Models

Implementation of Unigram and Bigram language models with linear interpolation smoothing.

**Location:** `ex1/`

**Quick Start:**
```bash
cd ex1
pip install -r requirements.txt
python -m spacy download en_core_web_sm
python main.py
```

See [ex1/README.md](ex1/README.md) for details.
